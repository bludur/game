# Witchroot 0.4.0-alpha — протокол внешнего playtest

Цель — провести 20 независимых полных сессий на чистой Windows-сборке и решить,
готова ли двухрегионная дуга к дальнейшему расширению. Разработчик не объясняет
управление до запроса игрока; каждое вмешательство отмечается.

## Маршрут одной сессии

1. Запуск из распакованного ZIP без редактора Godot.
2. Первое убежище и первая ночь в Пепельной роще.
3. Подготовка, Беззвёздный склеп и Rootbound Matriarch.
4. Создание портального фокуса и переход в Предел Мёртвой Луны.
5. Второй опорный пункт, ритуал затмения и Moon-Eater.
6. Возврат в Рощу и проверка сохранённых построек.

Ожидаемая длительность полного маршрута — 3–5 часов. Разрешены несколько запусков
одного save, но это остаётся одной сессией одного игрока.

## Что записывать

| Поле | Значение |
|---|---|
| Session ID | PT-01…PT-20 |
| ПК / GPU / разрешение / renderer | свободный текст |
| Устройство ввода | keyboard+mouse / gamepad |
| Время до первого очага | минуты |
| Первая ночь без вмешательства | да / нет |
| Дошёл до первого босса | да / нет |
| Победил первого босса | да / нет |
| Перешёл во второй регион | да / нет |
| Победил Moon-Eater | да / нет |
| Сохранение и возврат корректны | да / нет |
| Крэши / ошибки / потеря данных | количество и шаги воспроизведения |
| Вмешательства разработчика | количество и причина |
| Три главные проблемы | дословно со слов игрока |
| Оценка понятности / боя / темпа | 1–5 для каждого пункта |

## Правила triage

- одна строка issue на одну наблюдаемую проблему, без объединения симптомов;
- указывать частоту: `20/20`, `7/20`, `1/20`, а не «часто»;
- `P0`: crash, потеря save, невозможность продолжить;
- `P1`: блокирующая непонятность, soft-lock, недоступное управление;
- `P2`: повторяющаяся проблема темпа, баланса, читаемости или polish;
- после 20 сессий выбрать top-10 по тяжести × частоте и повторить затронутый
  участок минимум на пяти новых контрольных сессиях.

## Gate alpha 0.4.0

- 0 crash и 0 потерь сохранения;
- не менее 16 из 20 игроков доходят до первого босса без вмешательства;
- медианный переход региона менее 5 секунд на SSD;
- ни одна обязательная команда не остаётся недоступной после remapping;
- отсутствуют P0/P1, а исправленные top-10 имеют воспроизводимую проверку.

Заполненные результаты не коммитятся как «пройденные», пока реальные внешние
игроки не завершили сессии.
