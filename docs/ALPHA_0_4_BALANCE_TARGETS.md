# Witchroot 0.4.0-alpha — баланс-контракт

Это исходные authored-границы для внешнего playtest. Они предотвращают случайный
регресс контента, но не заменяют решения по данным 20 человеческих сессий.

| Участок | Цель alpha | Текущее значение / gate |
|---|---|---|
| Подготовка до первой ночи | 5–7 минут | 374 секунды |
| Первый фундамент | не более 3 базовых единиц | 3 gravewood |
| Малый безопасный очаг | не более 4 обработанных компонентов | 3 prepared gravewood + 1 core |
| Радиус малого очага | не менее 7 м | 7 м |
| Контр-подготовка к боссу | не более 4 ингредиентов на расходник | 3–4 |
| Один предмет Eclipse-tier | 4–6 компонентов | 4 / 5 / 6 |
| Фокус Великого портала | только после знания босса, не более 9 компонентов | knowledge gate + 9 |
| Второй регион | 60–90 минут после перехода | измеряется внешним playtest |

`tests/unit/test_alpha_balance_contract.gd` закрепляет машинно проверяемые строки.
После внешних сессий менять значения следует вместе с этим контрактом и указывать
частоту проблемы из `PLAYTEST_0_4_PROTOCOL.md`.
