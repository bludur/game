# Game Design — Draft 0.1

## Концепция

Игрок управляет магом в компактных трёхмерных локациях с видом сверху. Главная выразительная система — сочетание заклинаний, которые меняют состояние врагов и пространства.

## Цель первого вертикального среза

Десятиминутная одиночная сессия:

1. Игрок осваивает движение и базовый снаряд.
2. Получает второе заклинание с контролем области.
3. Побеждает два типа противников.
4. Выбирает одно улучшение.
5. Побеждает усиленную финальную волну.

## Принципы

- Заклинания должны хорошо читаться с высоты камеры.
- Каждое заклинание отличается не только уроном, но и способом применения.
- Арена компактна: игрок почти всегда видит ближайшую угрозу.
- Первый прототип не содержит крафта, строительства, процедурного мира и мультиплеера.

## Минимальный набор контента

- Маг: движение, направление взгляда, мана и здоровье.
- Заклинания: магический снаряд, круг замедления, короткий рывок.
- Враги: преследователь и дальнобойный культист.
- Одна арена с простыми препятствиями.
- Один экран завершения сессии.
