## Critical

Критических проблем, приводящих к падению, потере сохранения или дублированию

## Improvements

- [x] Скрытая карта могла запрашивать перерисовку каждый кадр — processing теперь
  выключается, пока карта не видна.
- [x] Системные уведомления и контентные названия были частично зашиты на русском —
  HUD, prompts, предметы, рецепты, постройки, ритуалы и сообщения имеют RU/EN
  семантические ключи.
- [x] SaveGameService пытался создавать каталог до первой записи — каталог
  создаётся только непосредственно перед сохранением.
- [x] Pickup изменял высоту накопительно — bobbing теперь вычисляется относительно
  фиксированной исходной высоты.
- [ ] Пулы врагов и pickup пока не нужны при лимите шести активных противников.
  Вернуться к ним только после профиля более насыщенного региона.
- [ ] Десять внешних playtest-сессий и финальный ручной баланс остаются воротами
  перед снятием суффикса -dev.

## Positive

- Системы разделены по сценам и компонентам; изменяемое состояние отделено от
  неизменяемых typed Resources.
- Все игровые действия идут через Input Map; непрерывная физика находится в
  physics process, одноразовые действия — в unhandled input.
- Сохранение использует стабильные region_id/persistent_id, временный файл,
  проверку JSON и backup.
- Headless-профиль Пепельной рощи: 380 узлов, 2625 объектов, 0 orphan nodes,
  около 0,46 мс process и 0,45 мс physics на локальном прогоне.
- Ускоренный soak прошёл 5400 логических секунд, 150 построек, три смерти,
  три охоты и три save/load; максимальная запись заняла 24 мс.
