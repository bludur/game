# Code Review — Vertical Slice 0.1.0

Проверено по чек-листам Godot 4.3+ после реализации пяти этапов.

## Critical

Критических ошибок, ведущих к падению, потере состояния или нарушению игрового
цикла, не найдено. Импорт, главная сцена, полная победная сессия, поражение и
перезапуск проходят headless.

## Improvements

- [x] Повторный синтез одинаковых аудиобуферов на каждом экземпляре врага —
  добавлен общий кэш `AudioStreamWAV` в `SyntheticAudio`.
- [x] Ресурс `Arcane Bolt` мог бы сохранять бонус между запусками при прямой
  мутации — `RunDirector` дублирует ресурс перед применением улучшения и возвращает
  исходные ссылки при рестарте.
- [x] Модальные окна могли зависеть от фиксированного разрешения — корневые слои
  переведены на full-rect anchors, содержимое размещено контейнерами, интерактивные
  элементы имеют минимальную высоту 44 px и клавиатурный фокус.
- [ ] Пул снарядов пока не нужен при текущем лимите четырёх врагов и низкой частоте
  стрельбы. Вернуться к нему, если профиль покажет частые пики `instantiate()` или
  количество врагов вырастет в несколько раз.

## Positive

- Сцены имеют узкие обязанности, а здоровье, мана, hurtbox, замедление, звук и
  рывок собраны композицией без глубокой иерархии наследования.
- Состояния игрока, врагов и сессии типизированы; одноразовые действия используют
  Input Map и `_unhandled_input()`.
- Сигналы передают изменения вверх (`defeated`, `wave_completed`,
  `upgrade_applied`), а владельцы управляют дочерними системами публичными методами.
- В горячих циклах нет `get_node()`/`load()`; навигационная цель обновляется таймером,
  а не каждый кадр.
- Финальная волна укладывается в бюджет прототипа: 237 узлов, 2063 объекта,
  0 осиротевших узлов, около 0,24 мс process и 0,61 мс physics в headless-прогоне.
