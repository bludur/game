# Производительность 0.3.0-dev

## Бюджеты арены

| Метрика | Бюджет | Прогон 0.3.0-dev |
|---|---:|---:|
| Частота кадров | 60 FPS | целевая |
| Process после прогрева | ≤ 25 мс | 0,91 мс |
| Physics после прогрева | ≤ 25 мс | 2,69 мс |
| Узлы усиленной волны | ≤ 500 | 369 |
| Объекты | ≤ 2550 | 2519 |
| Orphan nodes после 5 сессий | 0 прироста | 0 прироста |

Числа получены на текущем Windows-устройстве в headless Forward+ запуске
`tests/qa/performance_smoke_test.gd`. Бюджет объектов увеличен на 2% для typed-каталога
состояний этапа 23; лимиты времени и узлов не ослаблены. Первые 120 physics-кадров отведены на
загрузку импортированных ресурсов и синхронизацию навигационной карты; бюджет
измеряет обычный бой после прогрева. Это CPU-smoke, а не универсальный GPU-бенчмарк.

В визуальном Forward+ movie-прогоне на NVIDIA GeForce RTX 3060 средний GPU render
был 3,94 мс/кадр, CPU render — 0,85 мс/кадр. Encoding PNG в эти числа не входит.

Compatibility отдельно запускает главную сцену через
`--rendering-method gl_compatibility`. Визуальный Forward+ preview следует
проверять на целевом GPU командой из [screenshots/README.md](screenshots/README.md).

При расширении арены порог блокировки CI остаётся 25 мс. Если он превышен,
сначала фиксируется профиль конкретного кадра; визуальные эффекты или навигация
упрощаются только после определения источника пика.
