# Tests

- `qa/project_smoke_test.gd` проверяет загрузку основной сцены, игрока, камеры,
  целей, врага, навигации и создание снаряда без графического окна.
- `qa/enemy_chase_test.gd` за четыре секунды подтверждает реальную погоню и
  успешную ближнюю атаку по магу.
- `qa/third_person_locomotion_course_test.gd` проверяет сжатие SpringArm перед
  стеной, расход общей выносливости и невозможность уклониться сквозь препятствие.
- `qa/performance_smoke_test.gd` запускает усиленную финальную волну и проверяет
  бюджет узлов, объектов, 25-мс порог и отсутствие осиротевших узлов.
- `qa/release_flow_test.gd` проводит пять полных сессий, включая победу,
  поражение, рестарт, меню, локализацию, настройки и локальные метрики.
- `unit/` содержит тесты GUT для ресурсов, здоровья, маны, фракций, возрождения,
  заклинаний, рывка, дальнего культиста, полной сессии, обеих концовок и чистого
  перезапуска после улучшения.
- `unit/test_tutorial_director.gd` проверяет порядок неблокирующих уроков и skip.
- `visual/combat_preview.tscn` автоматически выпускает `Chain Lightning` для
  ручной проверки дальности, цепи, камеры, HUD и читаемости VFX.
- `visual/session_preview.tscn` автоматически доходит до выбора руны для проверки
  модального UI на разных разрешениях.
- `visual/boss_preview.tscn` запускает Хранителя арены и его телеграфы отдельно.
- `visual/third_person_locomotion_course.tscn` — ручная полоса стен, колонн,
  низкого потолка, склона и лестницы для keyboard/mouse и gamepad playtest.
- `visual/victory_preview.tscn` продолжает автоматическую сессию до экрана победы.
- `visual/defeat_preview.tscn` показывает экран поражения после летального урона.

Запуск всех проверок:

```powershell
.\tools\qa\run_checks.ps1
```
