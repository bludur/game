# Mage Prototype

Стартовый проект одиночной top-down 3D-игры про мага.

## Технологии

- Godot 4.7.2, Forward+
- типизированный GDScript
- Blender 5.2 LTS для 3D
- Krita для концептов и текстур
- Git + Git LFS
- GUT для модульных тестов и собственные headless smoke-тесты

В репозитории зафиксирован GUT 9.7.1, совместимый с Godot 4.7.
Его тестовый раннер работает из командной строки. Панель плагина намеренно не
включается автоматически, чтобы редактор не выполнял фоновую сетевую проверку
версии; при необходимости её можно включить в `Project Settings → Plugins`.

## Быстрый запуск

```powershell
.\tools\godot.ps1 --editor --path .
```

Запустить игру без редактора:

```powershell
.\tools\godot.ps1 --path .
```

Локальный launcher выбирает самую свежую установленную WinGet-версию Godot и не зависит от устаревшего Windows App Alias.

Управление:

- `WASD` — движение относительно камеры;
- левая кнопка мыши — прицелиться по плоскости арены и выпустить `Arcane Bolt`;
- `Shift` — зарезервирован под рывок;
- `Esc` — пауза/меню в будущей версии.

## Текущий вертикальный срез

Сейчас работает первый боевой цикл: маг перемещается, тратит восстанавливаемую
ману, выпускает видимый снаряд с VFX и наносит урон тренировочным кристаллам или
преследующему его Теневому охотнику. Враг обходит препятствия, атакует вблизи,
умирает и возрождается; побеждённый маг также возвращается на старт. HUD показывает
здоровье, ману и перезарядку. Следующая продуктовая цель — звук попаданий и атмосфера
из [плана вертикального среза](docs/plans/vertical_slice.md).
