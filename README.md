# Witchroot: Arena of Omens

Стартовый проект одиночной top-down 3D-игры про мага.

## Технологии

- Godot 4.7.2, Forward+
- типизированный GDScript
- Blender 5.2 LTS для 3D
- Krita для концептов и текстур
- Git + Git LFS
- GUT для модульных тестов и собственные headless smoke-тесты

В репозитории зафиксирован GUT 9.7.1, совместимый с Godot 4.7.
Его тестовый раннер работает из командной строки. Панель плагина намеренно не
включается автоматически, чтобы редактор не выполнял фоновую сетевую проверку
версии; при необходимости её можно включить в `Project Settings → Plugins`.

## Быстрый запуск

```powershell
.\tools\godot.ps1 --editor --path .
```

Запустить игру без редактора:

```powershell
.\tools\godot.ps1 --path .
```

Локальный launcher выбирает самую свежую установленную WinGet-версию Godot и не зависит от устаревшего Windows App Alias.

Управление:

- `WASD` — движение относительно камеры;
- левая кнопка мыши — прицелиться по плоскости арены и выпустить `Arcane Bolt`;
- `Shift` — рывок с коротким окном неуязвимости;
- `1` / `2` / `3` — выбрать `Arcane Bolt`, `Frost Circle` или `Chain Lightning`;
- `Esc` — пауза;
- `F1` — скрыть контекстное обучение.

## Проверки

```powershell
.\tools\qa\run_checks.ps1
```

Собрать Windows-версию и архив (после установки export templates Godot 4.7.2):

```powershell
.\tools\build_windows.ps1
```

Результат: `build/Witchroot-0.2.0-Windows-x86_64.zip`.

Подробности установки на новом Windows-компьютере: [docs/SETUP_WINDOWS.md](docs/SETUP_WINDOWS.md).
Правила работы с Codex и приоритетные Godot-скилы: [docs/AI_WORKFLOW.md](docs/AI_WORKFLOW.md).

## Текущий вертикальный срез

Работает релиз-кандидат `0.2.0`: две обычные волны и отдельный бой с двухфазным
Хранителем арены. Маг перемещается, делает рывок, расходует восстанавливаемую ману
и переключает прямой `Arcane Bolt`, контролирующий пространство `Frost Circle` и
групповой `Chain Lightning`. После второй волны игра предлагает три уникальные
руны из набора шести. Главное меню, пауза, настройки, русский/английский языки,
геймпад, контекстное обучение и локальный журнал результатов превращают
вертикальный срез в самостоятельную демоверсию. Синтезированные звуки, музыка и
атмосфера не требуют внешнего набора ассетов.
