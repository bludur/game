# Mage Prototype

## GodotPrompter

This is a Godot project with GodotPrompter skills available. Before implementing
any game system, check for a matching `godot-prompter:*` skill and use it. This
applies to every agent and session working in this repository.

Key skills: `player-controller`, `state-machine`, `scene-organization`,
`component-system`, `resource-pattern`, `godot-ui`, `hud-system`,
`ai-navigation`, `camera-system`, `audio-system`, `save-load`,
`inventory-system`, and `godot-testing`.

Use `AGENTS.md` as the authoritative source for product scope, architecture,
code style, and required checks.
