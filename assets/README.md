# Assets

- `models/` — исходные и экспортированные 3D-модели (`.blend`, `.glb`).
- `textures/` — игровые текстуры; исходники Krita можно хранить рядом в `.kra`.
- `audio/music/` — музыка.
- `audio/sfx/` — звуковые эффекты.
- `fonts/` — шрифты вместе с файлами лицензий.

Для каждого стороннего набора ассетов добавляйте рядом файл `LICENSE` или `SOURCE.md`.
